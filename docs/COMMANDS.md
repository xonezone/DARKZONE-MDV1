# 📚 Command List

Every command in **Dark Zone MD**, grouped by category.

Default prefix: **`.`** (change it with `.setprefix`). In WhatsApp, send **`.menu`** to see the live menu.

> Some commands need an AI key or the extra tools from the [setup guide](DEPLOY.md). Owner and group commands need the right permissions.
