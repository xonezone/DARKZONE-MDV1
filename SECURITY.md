# 🔒 Security Policy

## Found a security problem?
Please **do not** open a public issue for it.

Report it privately instead:
- Use GitHub: **Security tab → Report a vulnerability**
- Or message the owner on [WhatsApp](https://wa.me/923309333332)

Include what you found, how to repeat it, and what could go wrong. We will reply as soon as we can.

## Keep your own bot safe
- 🔑 Never upload your `.env` file. Only `.env.example` belongs on GitHub.
- 📱 Never upload WhatsApp session or login files (for example `creds.json`).
- 🔑 A **Session ID** works like a password for your WhatsApp. Never share it, post it, or put it in a public repo.
- 🔁 If a key or token leaks, **delete it and make a new one** straight away.
- 🔌 If a session leaks, open WhatsApp → **Linked devices** and log that device out.
- 👤 Keep the bot owner number private to people you trust.
