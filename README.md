## 🌑 About

**Dark Zone MD** is a multi-device WhatsApp bot built with [Baileys](https://github.com/WhiskeySockets/Baileys) and TypeScript. It comes with a full **web dashboard**, **Telegram pairing**, a database for saving settings, and more than **500 commands** ready to use.

You link your WhatsApp once, then run everything from chat or from the dashboard.

> 🛡️ Built to be tidy. Commands live in small files by topic, so it is easy to read, change, and add your own.

### 📲 Link WhatsApp in 60 seconds

1. Open your bot in **Telegram** and send `/start`
2. Send `/pair 923001234567` (your own number, with country code, no `+`)
3. In WhatsApp go to **Linked devices → Link a device → Link with phone number instead**
4. Type the 8-letter code the bot sends you
5. Send `.menu` to your bot on WhatsApp 🎉

> 🔑 Want a **Session ID** to move the bot to another host? See [Get a Session ID](#-get-a-session-id).
> 🔒 A Session ID is like a password. Never share it or upload it to GitHub.

### 📱 Run it on your phone (Termux)

One command, then paste your Telegram bot token:

```bash
pkg install -y curl && curl -fsSLO https://raw.githubusercontent.com/xonezone/DARKZONE-MDV1/main/termux.sh && bash termux.sh install
```

## 🚀 Quick Start

### What you need

- **Node.js 22 or newer**
- **pnpm** (install it with `npm install -g pnpm`)
- **Git**
- A **PostgreSQL** database (free ones work, for example Neon or Supabase)
- **ffmpeg** and **yt-dlp** for audio, video and sticker commands
- A **Telegram bot token** from [@BotFather](https://t.me/BotFather)
- A free [Clerk](https://clerk.com) account for dashboard login

### 1. Download the project

```bash
git clone https://github.com/xonezone/DARKZONE-MDV1.git
cd DARKZONE-MDV1
```

### 2. Install

```bash
pnpm install
```

### 3. Add your settings

```bash
cp .env.example .env
```

Open `.env` and fill in your own values. See the [table below](#%EF%B8%8F-environment-variables).

> 🔒 **Never upload your `.env` file to GitHub.** It holds your private keys. It is already in `.gitignore`.

### 4. Set up the database

```bash
pnpm --filter @workspace/db run push
```

### 5. Start the bot

```bash
pnpm --filter @workspace/api-server run build
./start.sh
```

`start.sh` loads your `.env` file for you, then starts the bot.

> 🖥️ Running on a server? Follow the full **[Setup & Deploy Guide](docs/DEPLOY.md)**. It covers ffmpeg, yt-dlp and keeping the bot online 24/7 with PM2.

### 6. Start the dashboard (optional)

The dashboard needs two values when it starts: `PORT` and `BASE_PATH`.

```bash
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/whatsapp-dashboard run dev
```

### 7. Link your WhatsApp

Use your Telegram bot. You do not need the dashboard for this.

1. Open your bot in Telegram and send `/start`
2. Send `/pair 923001234567` (use your own number, with country code and no `+`)
3. In WhatsApp go to **Linked devices → Link a device → Link with phone number instead**, then type the code
4. Send **`.menu`** to your bot. 🎉

## 🔑 Get a Session ID

A **Session ID** lets you start the bot already linked to your WhatsApp, without Telegram or the dashboard.

<div align="center">

<a href="docs/HOSTING.md#-linking-whatsapp-works-on-every-host"><img src="https://img.shields.io/badge/🔑%20GET-PAIR%20CODE-a855f7?style=for-the-badge&labelColor=581c87&logo=whatsapp&logoColor=white" alt="Get Pair Code" /></a>

</div>

1. Open the bot owner's pairing page (its address ends in `/api/session-pair`). The owner must turn it on and host it online first
2. Type your WhatsApp number with the country code, and tick the box
3. In WhatsApp: **Settings → Linked devices → Link a device → Link with phone number instead**, then type the code
4. Your **Session ID** arrives in your own WhatsApp chat (*Message yourself*)
5. Paste it into the `SESSION_ID` setting of your bot, then start it

> 🔒 A Session ID is like a password for your WhatsApp. Never share it or put it in a public repo.
> Running your own pairing page? Read the [Session ID guide](docs/SESSION-ID.md), or the [Pairing Page guide](docs/PAIR-PAGE.md) to host one for free.

## ⚙️ Environment Variables

Copy these names from `.env.example` and fill in your own values.

| Name | Needed? | What it is |
|---|:---:|---|
| `DATABASE_URL` | ✅ Yes | Your PostgreSQL connection link |
| `PORT` | ✅ Yes | The port the bot server runs on |
| `NODE_ENV` | ✅ Yes | `development` or `production` |
| `TELEGRAM_BOT_TOKEN` | ✅ Yes | Token from @BotFather, for pairing |
| `TELEGRAM_FORCE_JOIN_CHAT` | Optional | A chat people must join first |
| `TELEGRAM_POLLING` | Optional | Telegram polling on or off |
| `CLERK_SECRET_KEY` | ✅ Yes | Clerk secret key, for dashboard login |
| `CLERK_PUBLISHABLE_KEY` | ✅ Yes | Clerk public key |
| `AI_INTEGRATIONS_OPENAI_API_KEY` | Optional | Turns on OpenAI features |
| `AI_INTEGRATIONS_OPENAI_BASE_URL` | Optional | OpenAI API link |
| `AI_INTEGRATIONS_GEMINI_API_KEY` | Optional | Turns on Gemini features |
| `AI_INTEGRATIONS_GEMINI_BASE_URL` | Optional | Gemini API link |
| `AI_INTEGRATIONS_OPENROUTER_API_KEY` | Optional | Turns on OpenRouter models |
| `AI_INTEGRATIONS_OPENROUTER_BASE_URL` | Optional | OpenRouter API link |
| `LOG_LEVEL` | Optional | `info`, `debug`, and so on |
| `SESSION_ID` | Optional | Start already linked to a WhatsApp account |
| `ENABLE_SESSION_PAIR` | Optional | `true` turns on the public pairing page |
| `PAIR_MAX_PER_HOUR` | Optional | Tries per visitor per hour (default 3) |
| `PAIR_MAX_CONCURRENT` | Optional | Pairings at the same time (default 5) |
| `YTDLP_COOKIES_FILE` | Optional | Path to a `cookies.txt` so Instagram and some YouTube videos work |
| `YTDLP_PROXY` | Optional | Proxy link, for hosts that YouTube, TikTok or Instagram block |

## 🧩 Add Your Own Command

Commands are small and easy to write. Open a file in `artifacts/api-server/src/lib/commands/handlers/` and add:

```ts
{
  name: "hello",
  aliases: ["hi"],
  category: "OTHER",
  desc: "Say hello",
  handler: async (ctx) => {
    await ctx.reply(`Hello from *${ctx.config.botName}*! 👋`);
  },
},
```

Then add `"hello"` to the matching list in `menu-data.ts` so it shows in the menu.

<br/>

</details>

<details>
<summary><b>How do I make it private?</b></summary>
<br/>
Use the <code>.mode</code> command to switch between public and private.
</details>

</details>

Run <code>npm install -g pnpm</code>, then close and reopen your terminal.
</details>
